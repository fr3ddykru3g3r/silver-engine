# Submission gate checklist

Do not submit until every required item is checked by the students and, where applicable, the adult/mentor responsible for forms and approval.

## Evidence consistency

- [ ] Historical baseline is recorded as `7bd7f0659b8ce2f4310d5c83f7d81b6db439c40b` and source-only run `34573237824` is retained as a PASS receipt.
- [ ] Every headline result is checked against the frozen replay/evidence record.
- [ ] `228 full-table onset windows` is never presented as `85 matched onset episodes` or vice versa.
- [ ] Joint-XGBoost TSS is consistently `0.726 -> 0.621 -> 0.437` for mapped -> episode-normalized -> new-onset evaluation.
- [ ] Sensitivity/FAR/FPR are not confused: 48.24% / 88.95% / 4.51%.
- [ ] Joint minus proton-free onset contrast is reported as `-0.040 [-0.163,+0.083]` where the formal exact repository value is needed.
- [ ] Negative freshness evidence and missingness limitations remain visible.

## Student ownership

- [ ] Each student rewrote or explicitly checked the final abstract, paper, research plan, poster text and video wording in their own words.
- [ ] Each student can derive/explain the target, three estimands, EMF, TSS, bootstrap unit, dependence problem, prior-exposure limitation and prospective-custody boundary without reading generated prose.
- [ ] Each retained citation has been opened/read and matched to the claim it supports.
- [ ] AI/programming/mentor support is disclosed according to the live applicable rules.

## Forms and approval

- [ ] Live IRIS/affiliated-fair/ISEF requirements were rechecked immediately before submission.
- [ ] Dates, roles, institutions/mentors and continuation/prospective-extension status are truthful and consistent across forms.
- [ ] Any prospective extension intended to count toward the same project is included in the approved plan before it begins where required.

## Presentation

- [ ] Mechanism graphic is legible at judging distance.
- [ ] Fixed-alert TSS figure uses the title: “Measured SEP forecast skill changes when repeated episodes and persistence are removed.”
- [ ] Final poster PDF has been print-proofed at intended dimensions.
- [ ] Video is 85–90 seconds and spoken naturally by the student(s).
- [ ] Three skeptical mock judging sessions have been completed.
- [ ] Every answer about missing data, false alarms, novelty, prior exposure and protected evidence matches the evidence record.

## Claim boundary

- [ ] No text says or implies that the historical replay is untouched prospective validation.
- [ ] No state-of-the-art, operational-certification, company-benefit, economic-savings or guaranteed-award claim appears.
- [ ] The classifier is described as a research comparator, not the external pilot product.
- [ ] External pilot product is described as a forecast-validity/evaluation/audit kit.

## Archive

- [ ] Frozen model-free and fixed-replay artifact archives/hashes are preserved outside temporary CI retention.
- [ ] Final submitted files are archived with date and checksum.
